- Primary Palette: Fresh Light Green (#4ADE80 / #22C55E), Pure White (#FFFFFF), Deep Black (#0F0F0F), and Soft Slate Gray (#F8FAFC / #1E293B) for dark text/elements.

- Backgrounds: Clean white and soft slate cards paired with bold light-green visual accents, borders, and CTA sections.

- Primary Buttons: Solid Light Green (#22C55E) background with dark text/white text, featuring sleek hover animations.

- Link Embedding: Ensure all "Apply Now" and "Register" buttons directly open the registration link: https://bit.ly/labsbybincom in a new tab.
